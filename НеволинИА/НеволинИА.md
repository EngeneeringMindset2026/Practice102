# Краткое описание покрытого тестами функционала
В качестве участка с низким покрытием выбран провайдер **`pydantic_settings/sources/providers/gcp.py`** (**`GoogleSecretManagerSettingsSource`** и **`GoogleSecretManagerMapping`**), отвечающий за загрузку значений настроек и версий секретов из Google Cloud Secret Manager. 
В **`tests/test_source_gcp_secret_manager.py`** с помощью моков/заглушек (**`SecretManagerServiceClient`**, **`NotFound`**, **`PermissionDenied`**, **`google_auth_default`** и **`import_gcp_secret_manager`**) разблокированы и проверены сценарии: 
- инициализации источника настроек и получения **`project_id`** / **`credentials`** (явно, из предыдущих источников или через auth по умолчанию); 
- чтения секретов и обработки ошибок доступа (**`PermissionDenied`**, отсутствие секрета **`NotFound`**, ошибки при получении списка секретов); 
- работы с регистрозависимостью (**`case_sensitive`**), коллизиями имён секретов, аннотацией версий (**`SecretVersion`**) и кешированием обращений.
# Используемые технологии, библиотеки для тестирования
- **Язык и окружение:** Python 3, виртуальное окружение (`.venv`), `pip` / `uv`, Git / GitHub, Neovim. 
- **Фреймворк и плагины тестирования:** `pytest`, `pytest-cov` (замер `% coverage` и ветвлений), `pytest-mock` / `unittest.mock` (`MockerFixture`, `monkeypatch` для изоляции внешних зависимостей GCP). 
- **Дополнительные зависимости:** `PyYAML` (`yaml`) для запуска тестов YAML-провайдера.
